# PRD: 오늘의 할일 (Today's To-Do) 웹페이지

- 작성일: 2026-11-02
- 상태: 설계 (구현 전)

---

## 1. 개요

### 1.1 배경
하루 단위로 해야 할 일을 빠르게 적고, 끝낸 일을 체크하며, 하루의 진행 상황을 한눈에 확인할 수 있는 가벼운 웹페이지가 필요하다. 회원가입이나 서버 없이 브라우저만으로 바로 쓸 수 있어야 한다.

### 1.2 목표
- 3초 안에 할 일을 추가할 수 있는 단순한 UX
- "오늘" 기준으로 집중: 오늘의 할 일과 진행률을 가장 먼저 보여준다
- 새로고침·브라우저 재시작 후에도 데이터 유지 (localStorage)
- 데스크톱과 모바일 모두에서 편하게 사용

### 1.3 비목표 (Non-goals, v1 범위 밖)
- 회원가입/로그인, 서버 동기화, 다중 기기 동기화
- 팀 공유·협업 기능
- 반복 일정, 알림(푸시), 캘린더 연동
- 하위 작업(서브태스크)

## 2. 대상 사용자 및 시나리오

| 페르소나 | 설명 |
|---|---|
| 직장인/학생 | 아침에 오늘 할 일 5~10개를 적고 하루 동안 체크 |
| 가벼운 메모형 사용자 | 앱 설치 없이 브라우저 탭 하나로 관리하고 싶음 |

**대표 시나리오**
1. 아침에 페이지를 열면 오늘 날짜와 빈 목록(또는 어제 못 끝낸 일 안내)이 보인다.
2. 입력창에 할 일을 입력하고 Enter → 목록에 추가된다.
3. 일을 끝내면 체크박스를 눌러 완료 처리 → 취소선 + 진행률 상승.
4. 실수로 잘못 적은 항목은 더블클릭으로 수정하거나 삭제한다.
5. 다음 날 페이지를 열면 어제 미완료 항목을 오늘로 가져올지 선택할 수 있다.

## 6. 데이터 설계

### 6.1 Todo 모델
```ts
interface Todo {
  id: string;          // crypto.randomUUID()
  text: string;        // 1~100자
  done: boolean;
  important: boolean;  // F-20
  date: string;        // "YYYY-MM-DD" (로컬 시간 기준 소속 날짜)
  order: number;       // 정렬용
  createdAt: number;   // epoch ms
  completedAt?: number;
}
```

### 6.2 저장 구조 (localStorage)
| Key | 값 | 설명 |
|---|---|---|
| `todolist:v1:todos` | `Todo[]` (JSON) | 전체 할 일 |
| `todolist:v1:settings` | `{ theme: "system" \| "light" \| "dark", lastVisitDate: string }` | 설정 및 마지막 방문일 |

- 스키마 버전(`v1`)을 키에 포함하여 향후 마이그레이션 대비
- JSON 파싱 실패 시 기존 데이터를 `todolist:v1:backup`에 보존하고 빈 목록으로 시작

### 6.3 핵심 로직
- **오늘 목록** = `todos.filter(t => t.date === today)`
- **정렬** = 중요(★) 우선 → 미완료 우선 → `order` 오름차순
- **이월(F-31)**: `lastVisitDate < today`이고 `date < today && !done` 항목이 있으면 배너 표시. [가져오기] 시 해당 항목의 `date`를 `today`로 변경
- **날짜 기준**: 사용자 로컬 시간대 자정 기준. 페이지가 열린 채 자정을 넘기면 다음 포커스/조작 시 날짜를 재계산

## 7. 기술 설계

### 7.1 기술 스택 (권장안)
| 구분 | 선택 | 사유 |
|---|---|---|
| 마크업/스타일 | HTML5 + CSS (CSS 변수로 테마) | 빌드 없이 실행 가능 |
| 로직 | Vanilla JavaScript (ES Modules) | 의존성 0, 규모에 적합 |
| 저장 | localStorage | 서버 불필요 |
| 테스트 | Vitest(로직 단위 테스트) — 선택 | storage/정렬/이월 로직 검증 |

> 대안: 기능 확장(P2 이후) 계획이 크면 Vite + React/TypeScript로 시작 가능. v1은 Vanilla 권장.

### 7.2 폴더 구조 (예정)
```
todolist/
├── prd.md
├── index.html
├── css/
│   └── style.css
└── js/
    ├── main.js        # 진입점, 이벤트 바인딩
    ├── store.js       # 상태 관리 + localStorage 입출력
    ├── todo.js        # Todo 생성/수정/정렬/필터/이월 순수 함수
    ├── render.js      # DOM 렌더링
    └── date.js        # 날짜 유틸 (today, format)
```

### 7.3 아키텍처
```
[사용자 이벤트] → main.js → store.dispatch(action)
                               │
                     todo.js (순수 함수로 상태 변경)
                               │
                 store: state 갱신 → localStorage 저장
                               │
                     render.js (state → DOM)
```
- 단방향 데이터 흐름: 상태 변경은 store를 통해서만
- 액션: `ADD`, `TOGGLE`, `EDIT`, `DELETE`, `UNDO_DELETE`, `CLEAR_DONE`, `TOGGLE_IMPORTANT`, `CARRY_OVER`, `SET_FILTER`, `SET_THEME`

## 9. 인수 기준 (MVP)

- [ ] 입력 후 Enter 시 목록 최하단(또는 정렬 규칙 위치)에 항목이 추가된다
- [ ] 빈 문자열/공백만 입력 시 추가되지 않는다
- [ ] 체크 시 진행률 숫자와 바가 즉시 갱신된다
- [ ] 더블클릭 수정 후 Esc를 누르면 원래 텍스트로 돌아간다
- [ ] 새로고침 후에도 목록과 완료 상태가 그대로 유지된다
- [ ] 375px 폭 모바일 화면에서 가로 스크롤 없이 모든 기능을 사용할 수 있다
- [ ] `<script>` 같은 입력이 실행되지 않고 텍스트로 표시된다
- [ ] 키보드만으로 추가·완료·삭제가 가능하다

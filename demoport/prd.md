## 2. 목표

- 방문자가 30초 안에 "누구이며, 무엇을 잘하는지"를 파악할 수 있다.

- 방문자가 쉽게 연락(이메일)할 수 있다.
- 데스크톱과 모바일 모두에서 깔끔하게 보인다.

## 3. 주요 기능 및 페이지 구성

단일 페이지(One-page) 구조로, 상단 내비게이션으로 각 섹션에 이동한다.

### 3.1 헤더 / 내비게이션
- 이름(또는 로고)
- 메뉴: About · Skills · Projects · Contact
- 스크롤 시 상단 고정, 모바일에서는 햄버거 메뉴

### 3.2 Hero (첫 화면)
- 이름, 한 줄 소개 (예: "Python & HTML5 개발자")
- 짧은 소개 문구
- CTA 버튼: "프로젝트 보기", "연락하기"

### 3.3 About (자기소개)
- 프로필 사진(선택)
- 개발 경력 및 관심 분야 소개
- 일하는 방식 / 강점

### 3.4 Skills (기술 스택)
- **주력**: Python, HTML5
- **관련 기술**(예시, 추후 확정): CSS3, JavaScript, Flask/Django, Git
- 카드 또는 배지 형태로 표시, 주력 기술은 강조

### 3.5 Projects (프로젝트)
- 프로젝트 카드 목록 (최소 3개)
- 각 카드: 제목, 설명, 사용 기술 태그, 썸네일(선택), GitHub/데모 링크
- 프로젝트 데이터는 별도 데이터(JSON 또는 JS 배열)로 관리해 추가/수정이 쉽도록 한다.

### 3.6 Contact (연락처)
- 이메일: hvely1227@gmail.com (`mailto:` 링크)
- 이메일 주소 복사 버튼
- GitHub 등 외부 링크(선택, 추후 확정)

### 3.7 Footer
- 저작권 표기 (© 2026 demoport)
